사용량 관리
AI 일정 제안
공지에서 시험·휴강·온라인·보강을 뽑아 보여줍니다. 각 제안을 승인하면 캘린더에 들어가고, 거절하면 다시 묻지 않습니다. 자동 등록은 없습니다.
등록된 일정 (오늘 이후)
동기화
KLMS·포털·생활관에서 수집하고 드라이브·캘린더를 갱신합니다. 세션이 살아 있으면 폰 승인 없이 끝납니다.
마지막 결과
1. 학교 계정
로그인 창에서 아이디를 한 번 입력하면 저장됩니다. 비밀번호는 저장하지 않고, 다음부터는 폰 승인만 합니다.
2. 드라이브 폴더
자료를 저장할 폴더. 구글 드라이브 동기화 폴더 안을 추천합니다(폰에서도 보이게). 구글 드라이브 데스크톱이 없으면 PC 폴더로도 모든 기능이 됩니다(폰에서만 안 보임).
3. 구글 연결
마감·시험을 구글 "KLMS" 캘린더에 올립니다. "확인되지 않은 앱" 경고가 뜨면 고급 → 이동.
4. AI 모델
대화·일정 제안에 쓸 모델. 로컬은 내려받아 오프라인으로 돌아갑니다. 질문 화면에서도 바꿀 수 있어요.
ChatGPT 계정 (Plus/Pro 플랜)
API 키 없이 내 ChatGPT 플랜 한도로 씁니다. 질문 내용이 OpenAI로 전송됩니다.
브라우저에서 OpenAI 로그인·동의 화면이 열립니다. 이 앱은 비밀번호를 받지 않습니다. ChatGPT 대화 내용에는 접근하지 않습니다.
외부 AI (자기 API 키)
GPT·Claude·Gemini. 질문 내용이 그 서비스로 전송됩니다.
