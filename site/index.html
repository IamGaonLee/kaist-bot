무엇을 하나요

📥 자동 수집

KLMS 과제·공지·강의자료, 포털 시간표·학사일정, 생활관 정보를 한 번에 모읍니다.

🗓️ 캘린더 정리

마감과 시험을 구글 "KLMS" 캘린더에 자동 등록. 폰 캘린더에서 바로 봅니다.

📁 드라이브 정리

과목별 폴더에 자료를 내려받고, 읽기 쉬운 요약 PDF를 만들어 둡니다.

🔒 숨김 로그인

아이디만 저장(비밀번호는 저장 안 함). 로그인은 폰 승인 한 번이면 끝.

🤖 내장 AI

로컬 오픈소스 모델이 오프라인으로 질문에 답하고 일정 후보를 뽑습니다. ChatGPT Plus/Pro면 계정 로그인만으로 내 플랜을 쓰고, 자기 API 키로 GPT·Claude·Gemini도.

🔔 자동 동기화

트레이에 상주하며 주기적으로 갱신하고, 새 변경은 알림으로 알려줍니다.

다운로드

최신 설치 파일은 GitHub 릴리스에 올라옵니다.

KAISTBOT-Setup.exe 내려받기

설치 파일에 서명이 없으면 Windows가 "PC 보호" 경고를 띄웁니다. 추가 정보 → 실행을 누르면 설치됩니다. 처음 실행하면 설정 마법사가 계정·드라이브 폴더·구글 연결·AI 모델을 차례로 안내합니다.

처음 설정 (설치 마법사)

  1. 학교 계정 — 로그인 창에서 아이디를 한 번 입력하면 저장됩니다. 비밀번호는 저장하지 않고, 다음부터는 폰 승인만 합니다.
  2. 드라이브 폴더 — 자료를 저장할 구글 드라이브 폴더를 고릅니다.
  3. 구글 연결 — 마감·시험을 캘린더에 올립니다. 학교 메일(Gmail) 가져오기는 선택.
  4. AI 모델 — 오프라인 로컬 모델(1.5B/3B/7B)을 고르거나, Continue with ChatGPT로 내 ChatGPT 플랜을 쓰거나, 자기 API 키로 GPT·Claude·Gemini를 붙입니다.

개인정보와 안전

읽기만 합니다

제출·글쓰기·설정 변경은 하지 않습니다. 수집한 자료는 개인 학습용입니다.

비밀번호 미저장

학교 비밀번호는 저장·자동입력하지 않습니다. 2단계 인증(폰 승인)은 그대로.

내 기기에만

쿠키·성적·생활관 정보는 이 PC에만 둡니다. 성적은 드라이브·요약에 나가지 않습니다.
