사용 설명서

설치부터 매일 쓰기까지.

1. 설치

  1. KAISTBOT-Setup.exe를 내려받아 실행합니다.
  2. 서명이 없으면 Windows가 "PC 보호" 경고를 띄웁니다. 추가 정보 → 실행을 누르세요. (오픈소스 개인 앱이라 서명을 붙이지 않았습니다.)
  3. 설치가 끝나면 앱이 트레이(작업표시줄 오른쪽)에 상주합니다.

2. 처음 설정

앱을 처음 열면 설정 마법사가 뜹니다.

① 학교 계정

"로그인하고 아이디 저장"을 누르면 로그인 창이 뜹니다. 아이디를 한 번 입력하고 폰으로 승인하세요. 아이디는 이 PC에만 저장되고, 비밀번호는 저장하지 않습니다. 다음부터는 창 없이 폰 승인만 하면 됩니다.

② 드라이브 폴더

구글 드라이브 데스크톱은 필수가 아닙니다. 없으면 "구글 드라이브 없이 PC 폴더 쓰기"를 누르면 문서\KAIST에 저장되고, 동기화·질문·일정·캘린더 모두 그대로 됩니다(폰에서 자료 파일만 안 보임). 수집한 자료를 저장할 폴더를 고릅니다. 구글 드라이브(또는 원드라이브) 동기화 폴더 안을 추천합니다. 그래야 폰에서도 보입니다.

③ 구글 연결

"구글 승인"을 누르면 브라우저가 열립니다. 마감·시험을 올릴 캘린더 권한을 허용하세요. "확인되지 않은 앱" 경고가 나오면 고급 → 이동을 누릅니다. 학교 메일(Gmail) 가져오기는 체크박스로 선택합니다.

④ AI 모델

대화와 일정 추출에 쓸 모델을 고릅니다.

"모델 받기"를 누르면 내려받아 오프라인으로 돌아갑니다. 처음 한 번만 받고, 그다음부터는 인터넷 없이도 답합니다. 더 좋은 품질을 원하면 아래 외부 AI 연결을 보세요.

3. ChatGPT 계정으로 연결 (Continue with ChatGPT)

ChatGPT Plus·Pro를 쓰고 있다면 API 키 없이 내 ChatGPT 플랜 한도로 이 앱의 AI를 쓸 수 있습니다. Codex 앱이 ChatGPT 계정으로 로그인하는 것과 같은 공식 방식(OpenAI "Sign in with ChatGPT", 오픈소스·로컬 앱용)입니다. 추가 요금이 없고, 사용량은 ChatGPT 설정의 Usage에서 앱별로 관리합니다.

  1. 앱 설정 → 4. AI 모델 → ChatGPT 계정 (Plus/Pro 플랜) 카드를 누르고 Continue with ChatGPT를 누릅니다.
  2. 브라우저가 열리고 OpenAI 로그인·동의 화면이 나옵니다. 로그인하고 KAISTBOT이 내 ChatGPT 플랜을 쓰도록 허용합니다. 이 앱은 비밀번호를 받지 않고, ChatGPT 대화 내용에도 접근하지 않습니다.
  3. "로그인 완료"가 뜨면 창을 닫습니다. 설정 카드에 계정과 모델 목록이 보이고, 원하는 모델을 고른 뒤 선택 저장을 누릅니다.
  4. 질문 화면 드롭다운에 "모델명 · ChatGPT 플랜"이 보이면 끝입니다. 옆의 사용량 관리는 chatgpt.com 설정으로 바로 갑니다.
질문 내용과 근거 자료(과제 설명·공지 요약·일정)가 OpenAI로 전송됩니다(성적·호실은 제외). 로그인 토큰은 이 PC의 %LOCALAPPDATA%\kaist-cli\chatgpt-token.json에만 저장되며, 설정의 로그아웃으로 지울 수 있습니다. Plus는 5시간 단위 한도를 다른 앱(Codex 등)과 함께 씁니다. 한도에 닿으면 "ChatGPT 플랜 사용 한도" 오류가 나고, 잠시 뒤 다시 되거나 chatgpt.com → 설정 → Usage에서 앱별 한도를 조정할 수 있습니다. CLI는 kaist chatgpt login | status | logout.

Claude(Anthropic)는 제3자 앱의 Claude 계정 로그인을 약관으로 금지하고 있어 이런 방식은 없습니다. Claude·Gemini는 아래 API 키 방식으로만 연결됩니다. (Claude Max·Team 플랜에는 매달 API 크레딧이 포함돼 있어, 그 크레딧으로 키를 만들어 쓰면 됩니다.)

4. API 키로 연결 (GPT · Claude · Gemini)

ChatGPT 구독이 없거나 Claude·Gemini를 쓰려면 API 키만 넣으면 바로 씁니다. 앱이 해당 서비스의 OpenAI 호환 주소로 직접 요청을 보냅니다(SDK·추가 설치 없음). 세 가지만 알면 됩니다: API 키, Base URL, 모델명. 프리셋 버튼을 누르면 Base URL과 모델명은 자동으로 채워지고, 키만 붙여 넣으면 됩니다.

외부 AI를 쓰면 질문 내용과 그 근거 자료(과제 설명·공지 요약·일정)가 해당 서비스로 전송됩니다. 성적·생활관 호실은 보내지 않습니다. 키는 이 PC의 %LOCALAPPDATA%\kaist-cli\config.json에 평문으로 저장되니, 공용 PC에서는 쓰지 마세요.
서비스키 발급Base URL (프리셋)추천 모델 (프리셋)비용 감 (1M 토큰)
OpenAI (GPT)platform.openai.com → API keyshttps://api.openai.com/v1gpt-6-luna입력 $0.10 / 출력 $0.50

가격은 2026-10 기준 각 사 문서. 질문 한 번에 보통 2~5천 토큰이 들어가니, 하루 몇 번 쓰면 한 달에 몇백 원~몇천 원 수준입니다. 더 좋은 모델을 쓰려면 모델명만 바꾸면 됩니다(예: gpt-6.1-sol, claude-sonnet-5-5, gemini-3.8-flash).

순서

  1. 위 링크에서 키를 만듭니다. OpenAI·Anthropic은 결제 수단 등록(선불 충전)이 있어야 요청이 됩니다. Gemini는 무료 등급으로 시작할 수 있습니다.
  2. 앱 설정 → 4. AI 모델 → 외부 AI를 누르고, GPT / Claude / Gemini 프리셋 버튼 중 하나를 누릅니다.
  3. API 키를 붙여 넣고 선택 저장을 누릅니다. (Base URL·모델명은 프리셋 그대로 두면 됩니다.)
  4. 질문 화면 입력창 아래 모델 드롭다운에 "모델명 · 외부"가 보이면 연결된 것입니다. 아무거나 물어보세요.

로컬 ↔ ChatGPT 플랜 ↔ 외부 바꾸기

질문 화면의 모델 드롭다운에서 언제든 바꿉니다. 키와 ChatGPT 로그인은 지워지지 않으니 자유롭게 오가도 됩니다. 시험 기간엔 ChatGPT 플랜이나 외부, 평소엔 로컬처럼 쓰면 한도·비용을 아낄 수 있습니다.

"노력" 단계 (빠르게 / 보통 / 꼼꼼히)

  • 로컬 모델: 추론 단계가 없어서 답변 길이 상한만 달라집니다(300 / 600 / 1200 토큰). 긴 정리를 원하면 "꼼꼼히".
  • ChatGPT 플랜: 추론 모델이면 reasoning.effort로 전달됩니다(플랜 한도를 더 씁니다). 길이 상한 옵션은 쓸 수 없어 지시문으로만 조절합니다.
  • GPT·Gemini(API 키): reasoning_effort로 전달돼 실제로 더 오래 생각합니다. 비용·시간도 늘어납니다.
  • Claude(호환 주소): 이 값을 무시합니다. 모델 자체가 알아서 생각 깊이를 정합니다.

5. 매일 쓰기

  • 지금 동기화 — 홈 또는 트레이 메뉴에서. KLMS·포털·생활관을 수집하고 드라이브·캘린더를 갱신합니다. 세션이 살아 있으면 폰 승인 없이 끝납니다. 결과에 "새 일정 후보 N건"이 보이면 일정 화면으로 가서 승인·거절하세요.
  • 질문 — "이번 주 과제 뭐 있어?", "중간고사 일정 정리해줘", "동역학 HW4 뭐 내야 해?"처럼 물으면 모아둔 자료를 근거로 답합니다. 답 아래에 사용한 모델이 표시됩니다.
  • 일정 — AI가 공지에서 뽑은 시험·휴강·온라인·보강을 카드로 보여줍니다. 건마다 승인(캘린더 등록) / 거절(다시 묻지 않음). 아래 "등록된 일정"에서 이미 넣은 것을 취소할 수도 있습니다(두 번 눌러 확정).
  • 캘린더 — 마감·시험은 구글 "KLMS" 캘린더에 올라갑니다. 폰 캘린더 앱에서 바로 보세요.
  • 드라이브 — 과목 폴더의 _요약.pdf, _과목정보.pdf, 과제 설명.md와 첨부를 봅니다.

6. 제대로 쓰는 팁

동기화는 하루 1~2번이면 충분
아침에 한 번(앱이 켜져 있으면 07:00 자동), 저녁에 한 번. 너무 자주 누르면 학교 서버에 불필요한 요청이 갑니다. KLMS 과제 페이지는 새 과제·변경된 과제·마감 전 미제출만 열고, 게시글은 새 글만 한 번 엽니다.
세션 만료는 정상
학교 세션은 며칠마다 끊깁니다. 사이드바 상태 점이 노란색이면 "로그인"을 눌러 폰 승인 한 번만 하세요. 비밀번호는 묻지 않습니다.
AI 일정 제안은 "제안"입니다
AI가 뽑은 날짜는 틀릴 수 있어서 자동 등록을 하지 않습니다. 카드의 인용문(공지 원문)을 보고 날짜·시각이 맞는지 확인한 뒤 승인하세요. "검사 보류" 배지는 요일·학기 범위 검사를 통과 못 한 것이니 더 꼼꼼히 보세요.
질문은 구체적으로, 과목명은 KLMS 표기대로
"기계요소설계 중간고사 범위 알려줘"처럼 과목명을 넣으면 그 과목 자료만 찾아 정확해집니다. 로컬 3B 모델은 긴 질문·복잡한 추론에 약하니, 그럴 땐 외부 AI로 바꿔 보세요.
로컬 모델이 느리면
첫 질문은 모델을 메모리에 올리느라 10~20초 걸립니다. 그 뒤는 빨라집니다. RAM 8GB 이하 PC는 1.5B 모델을, GPU(Vulkan 지원)가 있으면 7B를 고려하세요.
"확인 필요" 마감
홈의 마감 목록에 "확인 필요" 배지가 붙으면 KLMS 캘린더와 과제 페이지의 마감이 서로 달랐다는 뜻입니다. KLMS에서 직접 확인하세요.
새 버전
시작할 때와 6시간마다 자동 확인합니다. 홈 배너나 사이드바의 "새 버전 다운로드"로 설치 파일을 받아 덮어쓰면 설정·자료는 그대로 남습니다.

7. 로그인 화면이 뜰 때

세션은 시간이 지나면 만료됩니다. 그때는 앱이 로그인을 요청합니다. 폰 승인만 하면 되고(아이디는 자동 입력), 인증 번호가 화면에 크게 뜨면 폰에서 그 번호를 고르세요. 비밀번호를 묻지 않습니다. 실패하면 화면에 이유(계정 잠금·거절 등)가 표시됩니다.

8. 개인정보

  • 읽기만 합니다 — 제출·글쓰기·설정 변경은 하지 않습니다.
  • 학교 비밀번호는 저장·자동입력하지 않습니다. 2단계 인증은 그대로 유지합니다.
  • 성적·생활관 호실은 이 PC에만 두고, 드라이브·요약·대화·외부 AI에 넣지 않습니다.
  • 받은 자료는 개인 학습용입니다. 공유 기능은 없습니다.

자주 묻는 것

PC를 꺼도 되나요?
끄면 그동안은 갱신이 안 됩니다. 켜져 있을 때 동기화합니다. 이미 받은 자료와 캘린더는 폰에서 계속 볼 수 있습니다.
휴대폰 앱은 없나요?
아직 없습니다. 대신 자료는 구글 드라이브 앱, 일정은 구글 캘린더 앱에서 그대로 보입니다. 폰에서 질문까지 하려면 PC가 켜져 있어야 합니다.
비밀번호를 왜 안 받나요?
KAIST 정보보안지침이 자동 비밀번호 입력을 금지합니다. 그래서 아이디만 넣고 폰 승인으로 로그인합니다.
외부 AI·ChatGPT 플랜을 쓰면 뭐가 나가나요?
질문 문장과, 답에 필요한 근거(과제 설명·공지 요약·일정 목록)입니다. 성적·호실·학번·비밀번호는 보내지 않습니다. ChatGPT 로그인은 이 앱이 내 ChatGPT 대화를 읽는 권한이 아니라, 플랜 한도로 모델을 부르는 권한만 받습니다.
동기화가 안 돼요
대부분 세션 만료입니다. 앱에서 "로그인"을 눌러 폰 승인을 해 주세요. 계속 안 되면 설정 → 1. 학교 계정에서 "다시 로그인"(창 표시)으로 화면을 직접 보며 로그인하세요.
